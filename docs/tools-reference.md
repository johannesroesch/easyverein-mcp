## Resources (read-only)

Resources sind cachebar und werden über URI-Templates adressiert. Sie spiegeln die gleichnamigen Tools wider, erfordern aber `resources/read` statt `tools/call`.

**URI-Schema:**
- Einzelobjekt: `easyverein://entity/{id}`
- Liste: `easyverein://entity{?limit,page}`

Beispiele:
- `easyverein://member/42` → `getMember` mit id=42
- `easyverein://member{?limit,page}` → `listMembers`
